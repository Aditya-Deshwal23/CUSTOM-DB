# Code of Conduct

We expect contributors and maintainers to communicate respectfully and
constructively. Harassment, discrimination, intimidation, personal attacks,
and publication of another person's private information are not acceptable.

Use the issue templates for project work and keep reports focused on the
technical behavior. Do not post credentials, private database contents, or
unpatched vulnerability details publicly. Report security issues through the
private process in [SECURITY.md](SECURITY.md).

Maintainers may edit, close, or remove contributions that violate this
standard and may restrict participation when necessary to protect the
community. To report a conduct concern privately, contact the repository
maintainers through GitHub.
